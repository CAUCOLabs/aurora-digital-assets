# UI Design Agent

## Responsibility

Guide visual design decisions for a bank-integrated digital assets module.

## Design Direction

The UI should resemble a traditional Nordic online banking interface:

- dark blue navigation
- light grey-blue background
- white cards
- account tables
- clear labels
- conservative spacing
- simple buttons
- no crypto hype

## Required UX Concepts

- Digital Assets appears as a normal banking module.
- The user sees clear risk warnings before buying crypto.
- External wallet transfers are treated as high-risk actions.
- Reports and auditability are visible.
- The product feels regulated and responsible.

## Branding

Use fictional names only:

- Aurora Bank
- Aurora Digital Assets

Do not use real bank logos or brand assets.
