# Frontend Agent

## Responsibility

Implement the online banking portal UI prototype for Aurora Digital Assets.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## UI Requirements

The interface must look like a serious Nordic online banking environment.

Required pages:

- Banking Dashboard
- Accounts
- Digital Assets Overview
- Buy/Sell
- Wallet
- External Withdrawals
- Reports
- Security & Compliance
- Settings

## Design Rules

- Do not create a trading platform UI.
- Do not use candlestick-heavy layouts as the main experience.
- Do not use neon colors.
- Do not use exchange-like gamification.
- Use calm banking colors.
- Prioritize trust, clarity, and readability.
- Use fictional bank branding: Aurora Bank.

## First Milestone

Create a static React prototype using local mock data.
