# Codex Project Context

## Project

Aurora Digital Assets — Bank-Integrated Crypto Wallet Framework

## Purpose

Build a concept prototype showing how a Finnish/Nordic bank could integrate a regulated digital assets wallet module into its existing online banking portal.

The prototype should demonstrate user experience, product architecture, compliance thinking, reporting, and controlled crypto withdrawal flows.

## Important Boundaries

This is a simulated prototype.

Do not use:

- real bank APIs
- real bank branding
- real customer data
- real crypto private keys
- real custody integrations
- real financial advice language

## Product Modules

The prototype should include:

1. Banking dashboard
2. Accounts overview
3. Digital Assets overview
4. Internal crypto wallet
5. Buy/Sell BTC and ETH flow
6. External wallet withdrawal flow
7. Risk education and warnings
8. Compliance status and audit trail
9. Tax report view
10. Mock PDF/CSV export concept

## Visual Style

Nordic online banking style:

- dark blue top navigation
- light grey-blue background
- white content cards
- clear account tables
- simple typography
- conservative buttons
- accessible contrast
- no speculative crypto design

## Technical Direction

Frontend:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

Backend:

- Python
- FastAPI
- SQLite or mock JSON first
- Pydantic models

Early versions may use mock JSON directly before backend integration.

## Key Message

The project is not about making crypto exciting.

The project is about making digital asset access safer, more transparent, more auditable, and more suitable for a regulated banking environment.
